# AI_Job_Search_Center
AI Job Search Center is a local Python app (except for API calls) to optimize your job search. 
a) Goal-Driven Planning: Set custom weekly schedules and gauge progress. 
b) Smart Matching &amp; Tailoring: Filter jobs by domain and auto-generate tailored resumes.
c) AI Advice &amp; Control: Get strategic insights based on your notes, and customize all AI prompts.
